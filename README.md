# COMANDO PX

Sistema operacional para motoristas baseado em IA, WhatsApp e Score PX.

## Visão Geral

O COMANDO PX captura cupons fiscais, notas e despesas enviadas pelo motorista via WhatsApp, processa os dados com Inteligência Artificial e gera:

- Score PX
- Conquistas
- Métricas operacionais
- Dashboard em tempo real
- Dossiê operacional do motorista

## Arquitetura

Motorista
↓
WhatsApp
↓
Google Forms
↓
Google Sheets
↓
Gemini OCR
↓
Score Engine
↓
Dashboard PX
